Convertissez vos températures en toute simplicité.

Cette application permet de convertir des degrés Celsius en Fahrenheit, et inversement. L'accès aux services est protégé par une authentification HTTP Basic.

Authentification requise pour chaque requête
GET °C → °F

De Celsius à Fahrenheit

Convertissez une température exprimée en degrés Celsius.

/temperature-converter/celsius-fahrenheit/50 Essayer avec 50 °C
GET °F → °C

De Fahrenheit à Celsius

Convertissez une température exprimée en degrés Fahrenheit.

/temperature-converter/fahrenheit-celsius/122 Essayer avec 122 °F

Conversion terminée

Comment utiliser l'API ?

Pour tester les services directement avec cURL, envoyez le nom d'utilisateur et le mot de passe dans chaque requête HTTP. 

curl -u user1:pass1 http://localhost:8080/temperature-converter/celsius-fahrenheit/50

Le serveur utilise Spring Security pour vérifier les informations d'identification avant d'autoriser l'accès aux services.

Cette page fournit une interface de démonstration. Les services de conversion restent accessibles directement à partir de l'API REST avec une authentification HTTP Basic valide.
